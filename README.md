# Hash World // Cipher Relay

A high-speed, arcade-style terminal cybersecurity cipher relay built for induction events and live crowd engagement.

## Features
* **Retro Terminal UI:** Custom CRT scanlines, monospaced fonts, and glowing neon green cyber aesthetics.
* **Multi-Stage Challenges:** Progressive cryptographic and encoding levels (Base64, Caesar Cipher, Binary, Hexadecimal, etc.).
* **Instant Feedback & Hints:** Real-time validation with shake animations on error and built-in hints for beginners.
* **Timed Rush:** Built-in countdown timer to create an edge-of-the-seat competitive atmosphere.
